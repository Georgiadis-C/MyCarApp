# MyCarApp 🚗

A comprehensive vehicle management and trip tracking application. Designed to help users monitor maintenance and log trips with real-time mapping.

## 🌟 Key Features
- **Map Integration:** Real-time routing and map visualization using **Mapsui** and **SkiaSharp**.
- **Trip Logger:** Record trips, track kilometers, and calculate fuel consumption automatically.
- **Maintenance Tracker:** Full UI for scheduling and viewing car service history.
- **Advanced UI:** Polished interface with custom styling, icons, and smooth navigation.
- **Architecture:** Built strictly on the **MVVM pattern** for maintainability.

## 🛠️ Tech Stack
- **Framework:** .NET MAUI
- **Graphics & Maps:** Mapsui, SkiaSharp
- **Patterns:** MVVM, Dependency Injection
- **Services:** Local Data Services for trip & maintenance records
